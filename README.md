## About PatrolTech

PatrolTech is guard tour and security patrol software developed by Ingenieros Web SL in Madrid, Spain. It combines QR/NFC checkpoint recording, offline patrol records, incident reports and a management dashboard.

Security companies, facilities teams and property managers use PatrolTech to organize sites and routes, record checkpoint visits and review synchronized patrol activity. The permanent free plan includes five checkpoints and unlimited guards; see the website for current plan limits.
